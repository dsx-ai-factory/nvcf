## NVCF 1.1.0

NVCF 1.1.0 selects Self-Managed 1.1.5, Compute Plane 1.1.0, and Observability
1.1.0. The [artifact manifest](../../docs/overview/manifest.md) records the
selected artifacts. Download the product archive and checksums from the
[NVCF 1.1.0 release](https://github.com/dsx-ai-factory/nvcf/releases/tag/nvcf/1.1.0),
then follow [Consume an NVCF release](../../docs/overview/umbrella-releases.md).

The 1.1.0 docs edition is available in the version selector. Version 1.0.4
remains the default while the
[1.0.1 to 1.1.0 upgrade procedure](../../docs/overview/release-notes/1.0.1-to-1.1.0-upgrade.md)
and its validation are completed. Publication does not establish a qualified
upgrade path. Track completion in the
[upgrade follow-up](https://github.com/dsx-ai-factory/nvcf/issues/3375).
Reviewed documentation corrections can update this edition without changing
the product tag or release assets. Making 1.1.0 the default requires a
separate reviewed docs change after upgrade validation is complete.

Further CVE remediation and eMudhra/emSign security backports are planned for
a subsequent 1.1.x patch. See the
[patch release follow-up](https://github.com/dsx-ai-factory/nvcf/issues/3187)
for scope and delivery status.
